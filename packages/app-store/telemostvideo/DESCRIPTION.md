Yandex Telemost is a video conferencing service by Yandex 360. With this integration every booking gets its own Telemost meeting link, created automatically on behalf of the connected account.

**Requirements:** the Telemost API is available only to **Yandex 360 for Business** users with an account on an organization domain. Connecting a personal (free) Yandex account will not work — meeting creation will fail with an authorization error.

Guests do not need a Yandex account to join: meetings are created without a waiting room, so attendees can open the link directly in a browser.
